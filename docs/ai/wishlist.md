# 🔮 Wishlist & Backlog

Ideas that are too cool to forget but not in the MVP scope yet.

## Future Features

- [ ] **AI Background Removal:** Integrate a client-side AI model (like `imgly/background-removal-js`) to automatically remove backgrounds without a server.
- [ ] **Passport Validations:** Auto-detect if eyes are closed or head is tilted using `face-api.js`.
- [ ] **Cloud Sync:** Optional Google Drive/Dropbox sync for backup (keeping it privacy-first by using user's own storage).
- [ ] **PWA Support:** Make it installable on mobile devices as a native-like app.
- [ ] **Dark Room Mode:** A UI theme specifically for low-light environments (photographer friendly).

## Tech Improvements

- [ ] **WebAssembly (Wasm):** Move heavy image processing (compression/filtering) to Rust/Wasm for performance.
- [ ] **WebGPU:** Utilizing WebGPU for real-time filters if WebGL is not enough.
